- **Restricted texts:** none included (all 29 checked).

## How to trace any text
1. Every file in `texts/<playlist>/` starts with a header giving its `id`, `source_url`,
   `translator_credit`, `lotsawa_version`, `retrieved` date and a ready-made `attribution` line.
2. `manifest.csv` lists all 29 texts in one table (id, playlist, title, author, translator, URL, version, file).
3. `raw/lotsawa_texts_2026-11-02.json` is the untouched download everything was built from.

If Lotsawa House updates a translation, compare its version number with `lotsawa_version`.

## Attribution format for the app
> Based on *[title]* by [author]. [translator_credit] Lotsawa House, CC BY-NC 4.0. [source_url]
